# Data

Only `prompt_templates.json` is included. Create the other input files as described below.

## Files

- `prompt_templates.json`: the prompt template for each instruction condition.
- `confirmation-of-first-person-belief.jsonl`: the first-person belief confirmation items (KaBLE Task 5). Download KaBLE from its repository and convert Task 5 to JSONL with one item per row. Each row needs `idx`, `query`, `raw_sentence` (the claim), and `type` (`factual` or `false`).
- Model outputs, strategy labels, and attention suppression results are generated by the scripts in `src/`. The files behind the paper's tables and figures are in `results/` (see [Released data](../README.md#released-data)).
