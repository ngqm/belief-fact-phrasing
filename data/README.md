# Data

Input datasets are not committed to this repository. This
directory ships only `prompt_templates.json`, the prompt templates used to build queries.
Recreate the rest locally as described below.

## What the code expects

- `data/prompt_templates.json`: included. Prompt templates per instruction condition.
- `data/confirmation-of-first-person-belief.jsonl`: the first-person belief confirmation
  items (KaBLE Task 5). Obtain KaBLE from its original release and convert to a JSONL where
  each row carries the claim and its truth label. The exact fields consumed are defined in
  `src/utils/dataset.py`.
- Derived artifacts (model outputs, the CoT strategy taxonomy, attention suppression result
  files): regenerated by the scripts in `src/`.

## Sources

- KaBLE: Suzgun et al., the belief and knowledge evaluation benchmark this study builds on.

Please follow the license terms of the source dataset. If you construct additional
evaluation items, place them here; the code reads paths relative to the repository root.
